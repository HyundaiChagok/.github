# HyundaiChagok/.github

[HyundaiChagok 조직 페이지](https://github.com/HyundaiChagok)에 보이는 소개 글을 두는 저장소입니다.

| 파일 | 내용 |
|---|---|
| [profile/README.md](profile/README.md) | 조직 페이지의 소개 글 |
| `profile/chagok-logo.svg`, `profile/chagok-logo-dark.svg` | 소개 글의 로고(밝은 바탕, 어두운 바탕). 원본과 사용 안내는 chagok 저장소의 `brand/`에 있습니다 |

조직 페이지에 보이려면 이 저장소가 공개여야 합니다. 앱 코드와 문서는 비공개 저장소에 있으니, 여기에는 공개해도 되는 내용만 둡니다.
