# HyundaiChagok/.github

[HyundaiChagok 조직 페이지](https://github.com/HyundaiChagok)에 보이는 소개 글을 두는 저장소입니다.

| 파일 | 내용 |
|---|---|
| [profile/README.md](profile/README.md) | 조직 페이지의 소개 글 |
| `profile/chagok-banner.svg`, `profile/chagok-banner-dark.svg` | 맨 위 배너(밝은 바탕, 어두운 바탕). 심벌의 기록 줄에 시연 기록을 적었습니다 |
| `profile/step-*.svg` | '어떻게 하나요'의 네 단계 그림. 단계마다 심벌이 한 층씩 완성됩니다 |

그림의 글자는 Noto Sans KR(SIL OFL 1.1)의 윤곽을 경로로 바꾼 것이라 보는 사람의 글꼴과 상관없이 같게 보입니다. 로고 원본과 사용 안내는 chagok 저장소의 `brand/`에 있습니다.

조직 페이지에 보이려면 이 저장소가 공개여야 합니다. 앱 코드와 문서는 비공개 저장소에 있으니, 여기에는 공개해도 되는 내용만 둡니다.
